# Laptop Price Predictor

## Overview

This project uses machine learning to predict laptop prices based on their technical specifications such as company, processor, RAM, storage, GPU, display, operating system, and weight.

The project includes data cleaning, exploratory data analysis, feature engineering, and regression model comparison.

## Project Workflow

* Data Cleaning
* Exploratory Data Analysis
* Feature Engineering
* Data Preprocessing
* Model Training
* Model Evaluation

## Models Used

* Linear Regression
* Ridge & Lasso Regression
* KNN Regressor
* Decision Tree
* Random Forest
* Extra Trees
* AdaBoost
* Gradient Boosting
* XGBoost
* Voting Regressor

Models were evaluated using:

* R² Score
* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
